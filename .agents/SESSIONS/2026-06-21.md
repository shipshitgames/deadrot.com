### Key decisions

1. **Main Deadrot comic style stays clean cel-comic.** Locked traits:
   big readable silhouettes, bold contour ink, flat hard shadow blocks, red/black
   graphic backgrounds, controlled grime, no dotted GPT texture, no halftone, no
   stipple, no noisy micro-detail fields.
2. **The second Pyre reference is the style anchor.** Use it as the prompt target:
   clean wall slabs, red breach shape, clear foreground hero/soldier shapes, minimal
   surface noise.
3. **Chorister cover concept is canon-valid.** The doorframe scene should read as
   a rooted Choir-repeater grown into architecture: throat-sac resonators, bone ribs,
   black chitin, toxic-green relay nodes, small Pyre/Warden squad at the threshold.
4. **Colorized manga-ink can be a variant cover or interior splash language.** It
   is not the base house style, but it has useful weight: brutal linework, cross-
   hatching, extreme black masses, controlled Deadrot palette.
5. **Typography comes after approved art.** Do not solve cover type while the art
   direction is still unstable.
6. **Current blocker: inline generations are not durable assets.** The Codex desktop
   image output shown in chat did not produce a local file in the normal cache, so
   it must be manually saved from the UI or regenerated through a file-writing image
   pipeline before it can enter `packages/assets`.
