# Scourge Survivors Assets

Runtime binaries moved to `@shipshitgames/assets`.

This folder keeps the runtime adapters used by existing game imports:

- `catalog.ts` wraps `@shipshitgames/assets/scourge-survivors` and adds local
  async Three.js texture helpers. It validates manifest paths against the
  assetgen-owned `../assets.generated.ts` typed index, while URL modules and
  image decoding remain lazy until the combat transition.
- `ui/pixelIcons.ts` re-exports packaged pixel icon IDs and URLs.

`assets.generated.ts` is generated by the studio-owned
`assetgen codegen --game scourge-survivors` command. Keep that output exact and
do not call its generic `loadAssets()` helper: Scourge uses the typed `ASSETS`
table, then loads only its explicit boot or combat surface through the packaged
catalog.

Source masters, drafts, generated originals, audio credits, and runtime files
live in:

`@shipshitgames/assets/games/scourge-survivors/`
