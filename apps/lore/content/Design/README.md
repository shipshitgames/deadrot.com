# Design Locks

The lore vault owns the visual truth. Games decline these locks into their own
camera, scale, and runtime formats.

Use this folder for per-subject visual design locks:

- `Design/Bestiary/<subject>-DESIGN.md`
- `Design/Locations/<subject>-DESIGN.md`
- `Design/Characters/<subject>-DESIGN.md`

Each design lock must point back to the canon page and [[Style-Bible]], then
declare the approved silhouette, material/color grammar, locked source poses,
game adaptations, and validation status.

Runtime assets in `packages/assets/games/...` are derivatives. They do not
define lore canon.

## Combat Key Art

- [[Art/Combat-Wallpapers-v05|Combat Wallpapers v05]]

Wallpaper/key art should look like realistic official promotional game
illustration: foreground heroes, distant enemy silhouettes, cracked ground,
rubble, smoke, embers, weathered armor, clean faction separation, and broad
red-black atmosphere. Keep the warzone grit, but keep it in large readable
forms. Do not let Scourge cores, background monsters, rim light, or fog turn
into speckled bloom, tiny point lights, firefly particles, stipple, halftone,
pixel grain, or dotted texture.
