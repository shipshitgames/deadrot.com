# Comic Style Exploration v01

Generated on 2026-06-17 as a Deadrot game-art and UI exploration pass.

This is not a replacement for the locked pixel-art bible. It is a test lane for
comic/cel-shaded game assets: thick ink outlines, smooth fills, readable shapes,
comic-panel UI, and no dotted/stippled grit.

## Direction

- Use this lane for exploration of game UI, menu art, character sheets, and
  possible non-pixel runtime assets.
- The Scourge still needs stronger parasite-host language: exposed host shells,
  invasive tendrils through armor seams, hijacked machinery, rupture cysts, and
  consumed anatomy should be visible even in comic style.
- Do not copy XIII or any named comic/game UI. Borrow the general grammar:
  panels, captions, inset kills, bold ink, and readable cel-shaded forms.
