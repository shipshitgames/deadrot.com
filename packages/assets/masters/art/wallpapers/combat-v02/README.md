# Deadrot Combat Wallpapers v02

Cleaned combat-key-art pass generated on 2026-06-17 for lore review.

These are high-resolution PNG masters for wallpaper, mood, and faction-read
reference. They are not runtime sprites and should not be shipped directly in a
game bundle without cropping, conversion to WebP, provenance review, and
manifest registration.

- `pyre-breach-descent-clean-wallpaper-v02.png` - Pyre Bulwark/Ranger breach
  descent against Rippers, Spitter, and Wound-Hound pressure.
- `warden-last-wall-clean-wallpaper-v02.png` - Warden Bastion/Lane-Gunner/

- `trucebreaker-arena-clean-wallpaper-v02.png` - Pactfall arena key art with
  Pyre and Warden champions facing Trucebreaker.

## Direction Lock

- Wallpaper/key art must read at thumbnail size.
- Use three to six large silhouettes, not a battlefield crowd.
- Separate humans and Scourge with value, posture, and accent color.
- Keep red breach light and dirty metal as the shared grade, but give each
  faction and foe a readable color lane.
- Avoid dotted, stippled, halftone, pixelated, over-sharpened, or
  micro-scratch-heavy finishes.
- Masters define visual direction. Runtime assets are derivatives.
