# Deadrot Combat Wallpapers v04

Clean promotional wallpaper pass generated on 2026-06-17 after rejecting the
gritty/dotted v03 direction.

These are high-resolution PNG masters for lore review and art-direction
reference. They are not runtime sprites and should not be shipped directly in a
game bundle without crop/export to WebP, provenance review, and manifest
registration.

## Files

- `clean-cgi-squad-standoff-wallpaper-v04.png` - cleaner CGI-style squad
  standoff with smooth platform and distant Scourge boss.
- `clean-poster-squad-standoff-wallpaper-v04.png` - preferred clean poster
  anchor with broad surfaces and the least grunge/noise.

## Direction Lock

- Use clean official promotional wallpaper language, closer to console game
  key art than creature concept art.
- Prefer smooth armor planes, clear silhouettes, and broad red-black
  atmospheric gradients.
- Put Scourge as distant silhouette unless it is a deliberate boss portrait.
- Avoid rubble floors, cracked ground closeups, debris fields, embers, dust,
  dirt speckles, scratch overlays, photobash grit, stippling, halftone, pixel
  grain, and all dotted texture.
- Runtime pixel grit and creature-study texture do not belong in wallpaper art.
